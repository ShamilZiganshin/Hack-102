# Кибер102 · Мобильный осмотр насоса

Оператор выбирает сценарий в HTML-сцене, сканирует QR-код телефоном и отправляет фотографию на компьютер. Сервер выполняет анализ ржавчины, масляных пятен и трещин. Четыре QR-кода открывают демонстрационные карточки насосов в локальной PostgreSQL.

## Запуск на Windows x64

1. Установите Git с Git LFS, Python 3.11 x64 с командой py, PostgreSQL 18 в стандартные каталоги Windows.
2. Выполните команды ниже. Для первого запуска потребуется интернет для зависимостей. На компьютере со старой копией стенда сначала завершите её процессы на портах 55440, 8769, 8443 и 8767.

~~~powershell
git clone https://github.com/Shamil65/Hack-102.git
cd Hack-102
.\START.bat
~~~

3. На ПК выберите сценарий. На телефоне в той же сети Wi-Fi отсканируйте QR на странице «Подключить телефон». Для непрерывной камеры следуйте инструкции по HTTPS на этой странице.

Автономную сцену можно открыть отдельно файлом «Насос — свободный 3D.html». Для анализа новых кадров нужен сервер. Ключи доступа и сертификаты создаются локально при настройке.

## Состав

| Компонент | Назначение |
| --- | --- |
| Насос — 3D и мобильный осмотр | Мобильная страница, HTML-сцена, сервер и обработчики фотографий |
| детекция ржавчины | UNet++ с энкодером ResNet50 |
| детекция масла | CLIPSeg и YOLO26 Nano |
| детекция поломок | InspectLab и YOLOv8n-seg для мобильной проверки трещин |
| Насосы_БД | Схема PostgreSQL и четыре синтетические карточки для QR |

Веса детекторов хранятся в Git LFS. Оригиналы паспортов хранятся отдельно у владельца стенда.
