# Кибер102 · Осмотр насоса с телефона

На ПК оператор выбирает сценарий в 3D-сцене, а на телефоне сканирует QR-код, открывает паспорт насоса из PostgreSQL и отправляет снимок на сервер. Стенд объединяет четыре сценария осмотра и три направления анализа изображений — ржавчину, масло и трещины.

## Запуск локального стенда

1. В каталоге `Хакатон 102 v2` откройте папку `Насос — 3D и мобильный осмотр` и запустите `START.bat`.
2. На ПК откройте [3D-сцену](http://127.0.0.1:8769/viewer.html) и выберите сценарий. Для автономного просмотра доступен файл `Насос — свободный 3D.html`.
3. Откройте `Подключить телефон.html`. На странице указаны адрес для телефона, QR-коды и код доступа. Для непрерывной работы камеры нужен доверенный HTTPS на порту `8443`.
4. На телефоне откройте паспорт и отправьте кадр на анализ. Проверка поломок включается отдельно и может занять несколько минут.

## Компоненты проекта

Папки перечислены относительно локального каталога `Хакатон 102 v2`.

| Папка | Назначение |
| --- | --- |
| Насос — 3D и мобильный осмотр | Основное приложение с 3D-сценой, мобильным интерфейсом и доступом к паспортам. |
| детекция ржавчины | UNet++ с ResNet50. Основной сервер вызывает `rust_model.py`. Ржавчина выделяется оранжевым. |
| детекция масла | CLIPSeg и YOLO26 Nano. Сервер вызывает `surface_model.py`. Основное приложение также использует окружение `.venv` из этой папки. |
| детекция поломок | InspectLab на порту `8767`. Режим `hybrid` объединяет YOLO и Qwen3-VL через локальную Ollama на порту `11435`. |
| 3D насосная — единая демонстрация | Первая версия сценарной сцены. Видеодемонстрация Full HD длится около 42 секунд и хранится в `outputs/demonstration.mp4`. |

## Паспорта и демонстрационные данные

Четыре QR-кода соответствуют реальным паспортам АМС. Рабочая копия PostgreSQL находится в `private/postgres` основного приложения. Имя базы — `pump_mobile`, порт — `55440`.

Геометрия насоса иллюстративная. Показания и пороги режима «Демо» заданы для сценариев. В исходной базе для этих насосов отсутствуют измерения и утверждённые уставки по ГОСТ.

В сцене доступны три реальные фотографии. Для каждой можно переключаться между оригиналом и сохранённой маской. Новый анализ запускается с телефона.

| Задача | Файлы основного приложения |
| --- | --- |
| Обслуживание телефона и работа с БД | `backend.py` |
| Запуск моделей | `worker.py` |
| Изменение мобильного интерфейса | `mobile.html` и `mobile.js` |
| Изменение 3D-сцены | Отредактируйте `viewer.html` и `viewer.js`, затем запустите `build_viewer.py`. Скрипт обновит автономный HTML и `public/viewer.html`. Сервер раздаёт файлы из `public/`. |

Описание проверок и результаты находятся в `README.md`, `Фотографии — выбор и проверка.md` и `outputs/verification.json` основного приложения.
