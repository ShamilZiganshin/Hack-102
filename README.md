# Hack102 — осмотр насосов с телефона

Стенд для Windows x64 объединяет 3D-сцену, паспорта четырёх демонстрационных насосов в PostgreSQL, непрерывный осмотр на NVIDIA GPU и историю показаний.

## Первый запуск из Git

1. Установите Git с Git LFS, Python 3.11 x64 с командой `py`, PostgreSQL 17 или 18 в стандартном каталоге и драйвер NVIDIA, совместимый с CUDA 12.8.
2. Клонируйте репозиторий и запустите **START.bat** в его корне. Понадобится интернет для Git LFS, CUDA-сборки PyTorch и Python-пакетов. Скрипт создаёт окружение, отдельный кластер БД на порту 55440 и запускает модели. При наличии локального кластера используется его версия PostgreSQL.
3. Дождитесь **READY**. На ПК откройте [3D-сцену](http://127.0.0.1:8769/viewer.html). В папке «Насос — 3D и мобильный осмотр» откройте «Подключить телефон.html». Для камеры на телефоне установите сертификат стенда по инструкции и используйте второй QR (HTTPS, порт 8443). Телефон и компьютер должны быть доступны друг другу по локальной сети.

## Обновление подготовленного RTX-ноутбука

Скачайте [архив для RTX](releases/Hack102-RTX.zip) через GitHub или получите его командой `git lfs pull`. Распакуйте содержимое в существующую папку Kiber102-Windows-GPU рядом с .venv, подтвердите замену файлов и запустите **START_RTX.bat**. Этот архив предназначен для уже установленного стенда. Скрипт проверяет CUDA и БД, при необходимости запускает её и перезапускает сервер этого проекта. Журналы находятся в outputs внутри каталога приложения.

## Демонстрация

Сфотографируйте QR насоса из сцены или выберите его в списке. Нажмите «Непрерывный осмотр». Кнопка «На весь экран» разворачивает камеру, «Выйти» возвращает страницу. В кадре отображаются значения, краткие ALERT и действия. Подробности и графики доступны ниже. Старая ссылка ar.html открывает главную страницу.

В демонстрации насос 001 работает в норме, 002 показывает перегрев и повышенную гармонику 1×, 003 — низкое давление и повышенную 2×, 004 — повышенные вибрацию, ток и ВЧ-шум. Вибрационные примеры взяты из 500 почасовых записей. Демо воспроизводит их ускоренно. Остальные демопоказания моделируются. Рекомендации служат подсказками для проверки. Автономный просмотр доступен в файле «Насос — свободный 3D.html».

Исходники сайта и моделей находятся в каталогах приложения и трёх детекторов. Базовые таблицы и демонстрационные паспорта создаются из SQL в Насосы_БД. Рабочая БД, ключи и параметры подключения создаются на компьютере запуска.
